# Release notes

Public release notes for Verzeta for Android. The release workflow publishes the
section whose heading matches the release version (`## [X.Y.Z]`) as the GitHub
release body. Format follows [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-07-10

The first public release of **Verzeta for Android**. It brings your Verzeta Studio project rooms to your phone.

Pair the app with your own Verzeta Studio desktop host and talk to your named-alias agent teams (`@Coord`, `@Researcher`, `@Writer`, `@Critic`) from anywhere your phone can reach the desktop.

### Highlights

- 1:1 and group conversations, with each agent's reply attributed inline.
- Project rooms with agent rosters, documents and group chats.
- Attachments, plus live canvas, artifacts, and generated media from the host.
- Run canvas scripts on the desktop from your phone, and answer their `input()` prompts from the console.
- Tasks, tool-call timelines, polls, and activity history.
- `@user` notifications when an agent mentions you.

### Privacy

Nothing runs on the device. All model, tool and agent work happens on your paired desktop. There is no telemetry, advertising or cloud account.

### Install

Install the **APK** from the assets below. The app is not on Google Play yet. You need a [Verzeta Studio](https://verzeta.com) desktop with its Remote Access server turned on.
