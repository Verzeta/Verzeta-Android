# Activity timeline (audit log)

The activity timeline is a read-only record of what agents, paired devices and tools did in a project. Use it to check what happened when several devices, scheduled heartbeats or multi-step plans were active.

## When to look at it

- "Who ran which tool in this project last week, and when?"
- "Did that heartbeat run on Monday?"
- "Which paired device approved that tool call?"

The timeline answers these from the records the desktop keeps.

## Open the timeline

For a project or organization, open the **Edit folder** sheet (see "Change a folder's settings" on the Projects and rooms page) and tap **View Activity Log**.

For one conversation, open it, then open the ⋮ menu and tap **Activity**. Going back returns you to the chat.

The **Activity Log** screen opens, newest events first.

Each row shows who acted (with a label for the kind of actor) and when, then the event type and tool name, then a summary of up to four lines. Below the summary, the row lists the event's recorded details, such as parameters and results, in monospace, up to six lines.

## Levels

The desktop keeps the timeline at three levels:

- **Project**: every event in a project or organization
- **Conversation**: every event in one conversation
- **Turn**: every event in a single assistant turn, in order

The app shows the project and conversation levels. It does not show the turn level.

## What you cannot do here

- Edit, delete or hide events. The log cannot be changed.
- Filter the timeline. The desktop can filter by actor and event type.
- Export the timeline.

For filtering, open the timeline on the desktop.
