# Projects, Project Rooms and group chats

Four related features help you organize multi-agent work:

- **Folders**: plain containers for conversations.
- **Projects** and **Organizations**: folders with members, preferred skills, project documents and scheduled heartbeats.
- **Project Rooms**: templates that create a ready-to-use project in one step.
- **Group chats**: conversations with several agents, either on their own or inside a project or organization.

## Create a project from a template (Project Rooms)

This is the quickest way to start a multi-agent project.

1. On the Home screen, tap the **Project Rooms** card. It appears while you are connected to a desktop.
2. Use the search bar or the category filters to narrow the list, then pick a template under **Start from a template**. To see the whole catalog, tap **Browse all** or **Quick start**, which open the Template Library.
3. The **Quick Start** screen opens with the template filled in. Pick a banner design with the arrows, then set the **PROJECT NAME** and **SCENARIO**. Describe the goal and add any background under **GOAL** and **PROJECT DESCRIPTION / CONTEXT**. Under **Teammates**, add, remove or rename members, star the coordinator, and set each member's provider, model and tools.
4. Tap **Create room**. The desktop creates the project with its members and preferred skills, and the app opens the Folders screen with the kickoff sheet for the new project.

To start without a template, tap **Blank** on the Project Rooms screen. The New folder sheet opens with the **Project** type selected.

Projects you already have appear under **Your rooms** on the Project Rooms screen.

## Save and pin templates

On the Quick Start screen, **Save as template** stores your version, including the banner design you picked, as a new template of your own.

Templates you saved yourself have a pin icon and a delete icon in the Template Library. Tap the pin icon to show the template on the Project Rooms screen. Built-in templates cannot be pinned or deleted.

## Change a folder's settings

In the **Chat** tab, long-press a folder header and tap **Edit folder**. The Folders screen opens with that folder's **Edit folder** sheet.

The Folders screen lists project and organization folders. Tap **All folders** at the top to also list regular folders, and **Projects + Orgs** to hide them again. While **All folders** is on, regular folders also appear in the Conversations list. Long-press a folder on the Folders screen for **Edit**, **Rename only**, **Convert to project** (regular folders only) and **Delete**.

If the desktop rejects a change, the sheet stays open with what you entered and the reason appears at the bottom of the screen.

The **Edit folder** sheet holds the folder's name, type, goal, description and members. For a saved project or organization, it also has **Project documents**, **Preferred skills**, **Project heartbeats** and a **View Activity Log** button.

Each member keeps the provider, model and tools set for it on the desktop when you save. You change those on the desktop.

**Folder types:**

- **Project**: a focused multi-agent effort.
- **Organization**: a top-level organization with the same options as a project.
- **Regular**: a plain folder for conversations, with no agents, goal or description. When you create one, the Folders screen switches to **All folders** so you can see it.

Switching a folder to Regular hides the project sections and clears its member list when you save.

## Kickoff sheet

After you save a project or organization that has at least one member, or create one from a template, the app asks "Start chatting with your team?" and offers two options:

- **Create a 1:1 conversation with each member**: one chat per member. Existing 1:1 chats are reused, so running kickoff again only adds the missing ones.
- **Start a group chat with all members**: one chat with everyone. It needs at least two members.

Tap **Start**, or **Not now** to skip.

## Create a group chat yourself

In the Conversations list, expand a project folder and tap **Start Group Chat with All**. The New Group screen opens with that folder's members already added. Outside a project, tap **New**, then **New group chat**.

When you add a member to a group chat inside a project, the picker shows only the project's members. Turn **Project members only** off to add an agent that is not on the project yet. It joins the project's roster when you tap **Create**.

To create the group chat, it needs a title and at least two included members, and every included member needs an alias that no other member uses. If you do not star a coordinator, the first member becomes the coordinator.

## Project documents

In the **Edit folder** sheet, use **Project documents** to upload files the assistant should use as references for the project. Each document can be up to 11 MB. Documents are uploaded straight to your desktop.
